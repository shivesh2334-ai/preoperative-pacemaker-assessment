# CIED Perioperative Management Assistant

Clinical decision support tool for managing patients with cardiac implantable electronic devices (pacemakers, ICDs) during surgery.

## Guidelines Implemented
- 2024 AHA Scientific Statement on Periprocedural CIED Management
- ASA Practice Advisory for Perioperative CIED Management
- HRS/BCN recommendations

## Usage
Open `index.html` in any modern browser or deploy to Vercel/Netlify.

## Features
- Risk stratification based on surgery location and EMI sources
- Device-specific recommendations (including leadless PMs, S-ICDs)
- Pacing dependency assessment
- Emergency vs elective pathways
